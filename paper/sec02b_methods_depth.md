# 2b. Methods in Depth: Validation, Engines and Amendments

## 2b.1 Exactness of the triad census
The triad census runs on a graph of 134,181 nodes and 2.7 million edges, where a generic routine takes close to an hour. We use an exact solver that expresses the 16 class counts through a small number of sparse-matrix quantities (counts of pairs, wedges and closed patterns, computed with blocked masked products) and recovers the class counts by solving an exact rational linear system. The solver was checked in two ways. On 166 synthetic graphs it matched igraph's census exactly. On the real graph it was checked against igraph's own census, which took 3,385 seconds, and all 16 class counts agreed as exact integers. The 16 observed counts are therefore exact, and all variability in the analysis comes from the nulls.

## 2b.2 Degree-preserving rewiring engines
The degree-preserving null (N1) replaces edges by repeated endpoint swaps. Each swap picks two edges (a to b, c to d) and replaces them with (a to d, c to b) if the result creates no loop and no duplicate edge, which preserves every node's in- and out-degree. We use 10 accepted swaps per edge. The null was first implemented in numpy with batched conservative rejection and then with a live hash set of edges, which is about 100 times faster on small graphs (about 0.5 seconds against 48 seconds for one 14,725-edge region). For the whole-brain compartment-preserving null and the within-neuropil analyses we use a C engine with identical acceptance semantics, a splitmix64 generator seeded per replicate, and a stall guard that returns early when 50 million consecutive proposals are rejected in a group that cannot be rewired. Engines differ in their random streams, so replicate-for-replicate equality across engines is not claimed, only equality of the null definition and reproducibility within an engine from its seed. All engines are covered by unit tests for exact degree preservation, simplicity, absence of loops and seed reproducibility.

## 2b.3 Mixing of the swap chain
Ten swaps per edge is a conventional choice and not a guarantee. We tested it. Chains were run for 20 swaps per edge with census snapshots at 0, 1, 2, 5, 10 and 20 swaps per edge on three seeded chains, with a plateau criterion fixed in advance: the relative change in a class count between 10 and 20 swaps per edge must be under 2% for every class whose count at 20 swaps is at least 100. The criterion failed for four classes (111D 3.0%, 111U 2.9%, 201 6.0%, 210 3.8%). The preregistration had already authorized escalation, so the diagnostic was rerun to 40 swaps per edge on three seeded chains (seeds 23, 24, 25). It still failed for eight classes, which we treat as mixing-unresolved (111D, 111U, 120C, 120D, 120U, 201, 210, 300). Their counts are small after rewiring, so small absolute drift gives large relative change. The eight classes that did converge (003, 012, 102, 021D, 021U, 021C, 030T, 030C) are the only ones allowed to carry headline claims. This diagnostic is the reason Section 3 states only those eight.

## 2b.4 The compartment-preserving null
The third null preserves, for every edge, the neuropil assigned to each endpoint as well as every node's degree. It rewires only within groups of edges that share the same pair of endpoint neuropils. Within the whole brain this produces a graph with the same compartment-level connectivity as the real brain. It does not preserve spatial position, because the v783 release has no soma coordinates; it is a region-level proxy and is named that way in the text. Inside a single neuropil, most edges fall in one group and the null can be near-degenerate (Section 3b.4).

## 2b.5 Statistics
A motif class is called significant when its two-sided p-value from the z-score, with Benjamini-Hochberg false discovery control at q = 0.05 across the 16 classes, falls below threshold in every null family. The whole-brain family is a separate family from the per-neuropil tests. Reciprocity, modularity, rich-club and neurotransmitter statistics are descriptive and carry no false-discovery claim. Controlled-experiment comparisons use exact Wilcoxon signed-rank tests paired by seed, with Holm correction over the primary tests in each family, at alpha = 0.05.

## 2b.6 Amendment history
The preregistration was locked and hashed before any outcome was computed, and every later change is a dated amendment that keeps the original text. In order:
1. Standing project rules, and a decision that failed gates trigger documented pivots, not an end to the project (Amendment 1).
2. A third, compartment-preserving null; per-structure computational hypotheses; null-count sensitivity; explicit false-discovery universe; neutral wording for neurotransmitter predictions; rich-club against null; Louvain stability (Amendment 2, before results).
3. Seeded null implementations, after the first runner was found to ignore its seeds in both null families; the interim unseeded nulls were discarded unanalyzed (Amendment 3, before z-scores were read).
4. A tiered inference hierarchy (confirmatory, robustness, exploratory), the convergence diagnostic, language for the compartment null, Stage C additions, and provenance checkpoints (Amendment 4).
5. The frozen mapping dictionary, the control ladder, a causal-triangle design, and the measured axes (Amendment 5).
6. The escalation of the swap-chain length after the convergence diagnostic failed at 20 swaps per edge (Amendment 6).
Later amendments (27 to 30) added the repaired arms and the follow-up comparisons reported in Section 6. Each is committed before its runs.

## 2b.7 Tests
The repository carries 29 automated tests in seven files, covering the census against a brute-force reference, the nulls (degree preservation, simplicity, reproducibility), the C engine, the compartment null, the stratification code, and the gradient of the sparse layer in training. The tests ran before each analysis whose outputs are reported here.
